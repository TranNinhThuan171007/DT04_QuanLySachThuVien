\section{Kiến trúc Module và Tổ chức Thư mục Mã nguồn}
Chương trình được tổ chức thành 4 phân hệ độc lập:
\begin{itemize}
    \item \texttt{src/models/}: Khai báo và hiện thực thực thể dữ liệu \texttt{Book}.
    \item \texttt{src/bst/}: Cài đặt cấu trúc dữ liệu cây \texttt{BST} và \texttt{BSTNode}.
    \item \texttt{src/storage/}: Cài đặt phân hệ đọc/ghi tệp CSV \texttt{FileStorage}.
    \item \texttt{src/ui/}: Hiện thực menu console tương tác và bắt lỗi nhập liệu.
\end{itemize}
