\addcontentsline{toc}{chapter}{Kết luận và Hướng phát triển}

\section*{Kết quả đạt được}
Qua quá trình thực hiện Đề tài 04 \textbf{"Quản lý danh mục sách thư viện bằng cây nhị phân tìm kiếm (BST)"}, nhóm sinh viên đã hoàn thành xuất sắc các mục tiêu đặt ra:
\begin{enumerate}
    \item Cài đặt hoàn chỉnh ứng dụng C++17 quản lý danh mục sách với đầy đủ các thao tác CRUD.
    \item Ứng dụng thành công cấu trúc cây BST động với cơ chế quản lý bộ nhớ an toàn tuyệt đối.
    \item Đọc và ghi tệp CSV bền vững, hỗ trợ lưu trữ lâu dài.
    \item Xây dựng báo cáo học thuật hoàn chỉnh, tài liệu phân công và quy trình Git/Jira mẫu mực.
\end{enumerate}

\section*{Hướng phát triển trong tương lai}
\begin{enumerate}
    \item Nâng cấp cấu trúc dữ liệu từ cây BST thông thường lên cây cân bằng tự động như \textbf{AVL Tree} hoặc \textbf{Red-Black Tree} để đảm bảo chiều cao luôn giữ ở mức $O(\log N)$, triệt tiêu trường hợp suy biến thành đường thẳng $O(N)$ khi dữ liệu nạp vào có thứ tự tăng/giảm dần.
    \item Tích hợp cơ sở dữ liệu quan hệ (SQLite/MySQL) và xây dựng RESTful API để kết nối ứng dụng Web với backend C++.
\end{enumerate}
